# Feasto - Frontend

The customer-facing React frontend for the Feasto AI-Powered Food Delivery Platform.

## Setup

1. Install dependencies:
    ```sh
    npm install
    ```

2. Start the development server:
    ```sh
    npm start
    ```

3. Open [`http://localhost:5173`](http://localhost:5173) in your browser.

## Tech Stack

- React 18
- Tailwind CSS 3
- React Router
- Axios
- React Toastify
