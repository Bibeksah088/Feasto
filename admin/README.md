# Feasto - Admin Dashboard

The admin dashboard for managing the Feasto AI-Powered Food Delivery Platform.

## Setup

1. Install dependencies:
    ```sh
    npm install
    ```

2. Start the development server:
    ```sh
    npm start
    ```

3. Open [`http://localhost:3000`](http://localhost:3000) in your browser.

## Tech Stack

- React 18
- Tailwind CSS 3
- React Router
- Axios
- React Toastify
